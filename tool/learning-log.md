Today, I learned about Math.js in JavaScript. Math.js is used to perform mathematical calculations in code. I learned that JavaScript has a built-in Math object that can help us solve math problems.

Some examples include:
```JS
Math.round(4.7) rounds a number to the nearest whole number.
Math.floor(4.9) rounds a number down.
Math.ceil(4.1) rounds a number up.
Math.sqrt(25) finds the square root of a number.
Math.random() generates a random number between 0 and 1.
```
What I learned:
I learned how to use math functions in JavaScript to make calculations easier.
